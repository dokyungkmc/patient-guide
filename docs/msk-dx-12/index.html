어떤 상태인가요

손목 관절 안의 윤활액이 새어 나와 작은 주머니(물혹)를 만든 것입니다.

암이 아닌 양성 혹이고, 시간이 지나면 저절로 줄어드는 경우도 많습니다.

아프지 않으면 지켜보면 되지만, 아프거나 빨리 커지면 초음파로 확인해 보는 것이 좋습니다.

혹을 세게 눌러 터뜨리는 민간요법은 하지 마세요.

회복 과정과 내원 주기

보통 12주 이상 정도 치료합니다

통증은 손목 사용을 줄이면 2~4주에 줄어듦. 혹 자체는 수개월~수년 사이 자연 소실되기도 하고 남아 있기도 함. 흡인 후 재발 흔함.

  1. 통증 있을 때 1~2주차

    주 2회

  2. 3~4주차

    주 1회

  3. 이후

    1~3개월마다 크기 확인

    빠르게 커지면 즉시

내원 횟수는 회복 속도에 따라 원장님이 조정합니다.

결절종 생활 관리와 지켜볼 때 주의

결절종은 관절·힘줄 주변에 물주머니가 생긴 것으로 양성이며, 절반 가까이는 저절로 작아지거나 없어집니다. 아프지 않으면 지켜봐도 됩니다.

실천 방법
  1. 힘으로 누르거나 책 등으로 때려 터뜨리지 않기
  2. 바늘로 찌르지 않기
  3. 크기가 커지면 손목을 덜 쓰고 쉬기
  4. 한 달에 한 번 크기를 사진으로 남겨 두기

언제 결절종이 있는 동안

주의 갑자기 커지거나 단단해지고, 손가락 저림·색 변화가 생기면 알려 주세요.

이럴 땐 바로 연락하거나 병원에 가세요

  • 다친 뒤 체중을 싣거나 손을 짚을 수 없을 때
  • 손발이 저리고 차가우며 색이 창백해질 때
  • 붓고 붉으며 뜨겁고 열이 날 때
  • 근육이 마르거나 감각이 아예 없어질 때
