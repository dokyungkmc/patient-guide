자세히 보기

누울 때는 무릎 아래 베개를 받치거나 옆으로 누워 다리 사이에 베개를 끼우면 편합니다.

  1. 2~3시간마다 5~10분 걷기
  2. 누울 때 무릎 아래 베개(바로 누울 때) 또는 다리 사이 베개(옆으로 누울 때)
  3. 침대에서 일어날 때는 옆으로 돌아누운 뒤 팔로 밀며 일어나기
  4. 허리 숙여 물건 들기·비틀기는 금지

주의 다리가 점점 힘이 빠지거나, 대소변이 불편하거나, 엉덩이 사이 감각이 무뎌지면 즉시 한의원에 연락하거나 응급실을 방문하세요.

  3. 물건을 배에 붙여 다리 힘으로 일어나기
  4. 든 채로 허리 비틀지 말고 발을 옮겨 방향 바꾸기

4집에서 하는 재활운동

진료 때 알려 드린 시기의 운동만 해 주세요. 하다가 아프거나 저림이 심해지면 바로 멈추세요.

통증기 0~2주회복 중 2~6주6주 이후재발 예방

고양이-낙타 체조

자생한방병원

해당 시기통증기 0~2주 · 회복 중 2~6주

횟수10회 × 하루 2~3번

하는 방법·멈출 때

네 발 기기 자세에서 등을 둥글게 말았다가 천천히 펴는 동작입니다.

굳은 허리를 부드럽게 풀어 주어 초기에 하기 좋습니다.

  1. 네 발 기기 자세(손은 어깨 아래, 무릎은 골반 아래)
  2. 숨을 내쉬며 등을 천장 쪽으로 둥글게 말기
  3. 숨을 들이쉬며 천천히 등을 편하게 펴기
  4. 아프지 않은 범위에서만 움직이기

이럴 땐 멈추세요 다리로 뻗치는 통증이나 저림이 심해지면 중단하세요.

네 발 기기 자세에서 반대쪽 팔과 다리를 뻗는 운동입니다.

허리를 흔들리지 않게 잡아 주는 속근육을 키워 재발을 막습니다.

  1. 네 발 기기 자세, 허리는 평평하게
  2. 한쪽 다리를 뒤로 뻗기(허리가 꺾이지 않게) → 익숙해지면 반대쪽 팔도 함께
  3. 5~8초 유지 후 내려오기

이럴 땐 멈추세요 다리를 너무 높이 들어 허리가 꺾이면 오히려 허리에 부담이 됩니다. 통증이 생기면 범위를 줄이세요.

횟수10회 × 2~3세트, 주 3~5일

하는 방법·멈출 때

누운 자세에서 엉덩이를 들어 올리는 운동입니다.

엉덩이 근육이 허리 대신 힘을 쓰도록 도와줍니다.

  1. 바로 누워 무릎 세우고 발은 골반 너비
  2. 배에 살짝 힘주고 엉덩이를 조여 어깨-골반-무릎이 일자가 되도록 들기
  3. 3~5초 유지 후 천천히 내리기

이럴 땐 멈추세요 허리를 과하게 젖히지 마세요. 허리가 아프면 높이를 낮추세요.
